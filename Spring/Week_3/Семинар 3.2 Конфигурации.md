## **Задание 1: @ComponentScan с фильтрами**

**Задача:** Настроить сканирование только определенных компонентов.

**Действия:**
1. Создайте три класса в разных пакетах с аннотациями:
    - `UserService` с `@Service` в пакете `com.example.service`
    - `LegacyService` с `@Service` в пакете `com.example.service`
    - `UserRepository` с `@Repository` в пакете `com.example.repository`

2. Создайте конфигурационный класс:
```java
@Configuration
@ComponentScan(
        basePackages = "ru.cu.seminar.seminar_3.task_2",
        includeFilters = @  ComponentScan.Filter(type = ANNOTATION, classes = Service.class),
        excludeFilters = @ComponentScan.Filter(type = REGEX, pattern = ".*Legacy.*"),
        useDefaultFilters = false
)
public class ScanConfig {}
```

3. Запустите приложение и проверьте, какие бины созданы. 
4. Важно: из-за специфики Spring Boot авто конфигураций надо config вынести в main. И итогово задание может выглядеть так:
```java
@Configuration

        includeFilters = @ComponentScan.Filter(type = ANNOTATION, classes = Service.class),
        excludeFilters = @ComponentScan.Filter(type = REGEX, pattern = ".*Legacy.*"),
        useDefaultFilters = false

@EnableAutoConfiguration
public class Application {

   public static void main(String[] args) {
      ConfigurableApplicationContext run = SpringApplication.run(Application.class, args);
      run.getBeanDefinitionNames();
   }
}
```

## **Задание 2: @Value с разными источниками**

**Задача:** Использовать @Value для инъекции значений из разных источников.

**Действия:**
1. Создайте `app.properties`:
```properties
app.name=TestApp
app.version=1.0
```

2. Создайте сервис:
```java
@Service
public class ConfigService {
    @Value("${app.name}")
    private String appName;
    
    @Value("${java.version}")
    private String javaVersion;
    
    @Value("#{systemProperties['user.home']}")
    private String userHome;
    
    @Value("${unknown:default}")
    private String defaultValue;
}
```

3. Проверьте, что все значения инъектятся корректно.

**Вопрос:** Что будет, если свойство `unknown` не найдено?

## **Задание 3: @ConfigurationProperties с валидацией**

**Задача:** Создать типобезопасную конфигурацию с валидацией.

**Действия:**
1. Создайте `application.yml`:
```properties
database.url=jdbc:h2:mem:test
database.username=admin
database.timeout=30s
database.pool-size=10
```

2. Добавьте зависимость: `spring-boot-starter-validation`

3. Создайте класс конфигурации:
```java
@Configuration
@ConfigurationProperties(prefix = "database")
@Validated
public class DatabaseConfig {
    @NotEmpty
    private String url;
    
    @Min(1) @Max(100)
    private int poolSize;
    
    @DurationMin(seconds = 1)
    private Duration timeout;
}
```

4. Запустите проект и посмотрите граничные значения при добавлении параметров.

## **Задание 4: Кастомный PropertySource**

**Задача:** Загрузить свойства из нестандартного источника.

**Действия:**
1. Создайте файл `custom.config` в каталоге resources:
```
custom.property=hello
```

2. Создайте конфигурационный класс:
```java
@Configuration
@PropertySource(
    value = "classpath:custom.config",
    name = "customProperties",
    ignoreResourceNotFound = false
)
public class CustomConfig {}
```

3. Используйте свойство в сервисе через `@Value("${custom.property}")`.

4. Измените файл `custom.config` и перезапустите приложение.

**Вопрос:** Можно ли изменять свойства без перезапуска?

## **Задание 5: SpEL в @Value**

**Задача:** Использовать Spring Expression Language в аннотации @Value.

**Действия:**
1. Создайте сервис:
```java
@Service
public class SpelService {
    @Value("#{T(java.lang.Math).random()}")
    private double random;
    
    @Value("#{configService.appName.toUpperCase()}")
    private String upperName;
    
    @Value("#{'${app.name}' + ' v' + '${app.version}'}")
    private String fullName;
    
    @Value("#{${values.map}}")
    private Map<String, Integer> map;
}
```

2. Добавьте в `application.properties`:
```properties
values.map={key1: 100, key2: 200}
```

3. Хоть и доступ до полей через SpEL работает через рефлексию. Чтобы выражение с upperName сработало, необходимо чтобы поле appName было либо как public, либо имело getter. 

4. Проверьте работу выражений.
