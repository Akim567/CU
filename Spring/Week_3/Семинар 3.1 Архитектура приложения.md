# Архитектура на уровне приложения

## **Задание 1: Слоистая (Layered) архитектура**

**Действия:**

1. **Создайте структуру пакетов по слоям:**
```
src/
└── main/
    └── java/
        └── com/
            └── example/
                └── library/
                    ├── controller/     # Уровень представления
                    ├── service/        # Бизнес-логика
                    ├── repository/     # Работа с данными
                    ├── model/          # Сущности предметной области
                    └── config/         # Конфигурация
```
2. **Добавьте экземпляры соответствующих классов:**

Сделайте это на примере Order (заказ) и payment (оплата). Используйте стереотипные аннотации


## **Задание 2: Модульная (Modular) архитектура**

**Действие:**

1. **Создайте структуру пакетов по модулям:**
```
src/
└── main/
    └── java/
        └── com/
            └── example/
                └── eshop/
                    ├── order/   # Модуль заказов
                    │   ├── OrderController.java
                    │   ├── OrderService.java
                    │   ├── OrderRepository.java
                    │   └── model/
                    │       └── Order.java
                    ├── payment/ # Модуль платежей
                    │   ├── PaymentController.java
                    │   ├── PaymentService.java
                    │   ├── PaymentRepository.java
                    │   └── model/
                    │       └── Payment.java
                    └── shared/           # Общие компоненты
                        ├── config/       # Конфигурации модулей
                        ├── dto/          # Общие DTO
                        └── exception/    # Общие исключения
```
